Box2D.Mover

Description

Friendly surface over the engine's mover plane solver.

The raw bindings (Box2D.Collision.solvePlanes / clipVector) work on a mutable b2CollisionPlane array: b2SolvePlanes accumulates each plane's push in place and b2ClipVector reads those accumulators back. The wrappers here own that mutation, so a kinematic character controller can stay in vector land:

(delta, planes', _iters) <- solvePlanes targetDelta planes
velocity' <- clipVector velocity planes'

Planes are normally assembled from the PlaneResults gathered by collideMover.

solvePlanes :: Vec2 -> Vector CollisionPlane -> IO (Vec2, Vector CollisionPlane, Int) #

Solve the position of a mover that satisfies the given collision planes. Returns the resolved translation, the planes with their final push accumulators (feed these to clipVector), and the solver iteration count (for diagnostics).

clipVector :: Vec2 -> Vector CollisionPlane -> IO Vec2 #

Clip a velocity against the given collision planes; planes with zero push or with clipVelocity unset are skipped. Call it on the planes returned by solvePlanes.
