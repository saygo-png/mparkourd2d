Box2D.UserData

Description

Integer-friendly user data: stash an entity/index id in the engine's void* userData slots without manual pointer casts. The id travels as the pointer's bit pattern (it is never dereferenced), so any Int that fits a word round-trips — which makes contact events and queries resolvable back to your entities.
